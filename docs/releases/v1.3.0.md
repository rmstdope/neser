# NESER v1.3.0 — September 29, 2026

NESER now plays Super Nintendo games, on desktop and in the browser, including the cartridges
with extra chips inside: Super FX, SA-1, CX4, S-DD1, OBC1 and the DSP family. Alongside it, NES
games line up frame for frame with the real console in far more places, and Game Boy players get new
palettes and colour correction.

## Highlights
- Super Nintendo support on desktop and web
- Star Fox, Super Mario RPG and Mega Man X2 run with their chips
- Super Scope and SNES Mouse on your mouse
- Game Boy palettes on F8

## New
- **Super Nintendo / Super Famicom**: a new system, on desktop and web. Loads `.sfc` and `.smc`
  ROMs, NTSC and PAL, with sound, save states, hi-res and interlaced modes, Mode 7 and all the
  standard graphics effects.
- SNES enhancement chips: Super FX (Star Fox, Stunt Race FX, Vortex, Yoshi's Island), SA-1
  (Super Mario RPG, Kirby Super Star), CX4 (Mega Man X2 and X3), S-DD1 (Star Ocean, Street
  Fighter Alpha 2) and OBC1 (Metal Combat: Falcon's Revenge).
- SNES DSP-1, DSP-2, DSP-3 and DSP-4 games (Super Mario Kart, Pilotwings, Dungeon Master, SD
  Gundam GX, Top Gear 3000) run when you supply the genuine chip firmware file; NESER checks it is
  the real one.
- SNES controllers: two standard pads, the multitap, the Super Scope and the SNES Mouse. Super
  Scope and SNES Mouse games are played with your computer's mouse, on desktop and web.
- SNES screen filters: choose one with F4, or the Filter button on the web.
- Game Boy: choose the shade palette for original Game Boy games, or any of the Game Boy Color's
  12 palettes, and cycle through them with F8 (the Palette button on the web).
- Game Boy Color and Game Boy Advance: F8 (the Colors button on the web) switches LCD colour
  correction on and off.
- Web: original Game Boy games can run on the Game Boy Color when you choose it, with Game Boy
  save states.
- Web: Game Boy Advance games get the same screen looks as on desktop.
- NES light gun: the sight is now a white ring, like the Super Scope's.
- Game Boy Color: link-cable serial transfers work, including the fast clock.
- The web file picker accepts SNES ROMs, and the web ROM list finds ROMs in linked folders.

## Fixed
- Vs. Duck Hunt (Vs. System): coins can be inserted and the Zapper fires on desktop. The web
  version still cannot insert a coin; that fix follows in a later release.
- StarTropics keeps its save RAM.
- Nintendo World Championships (NES-EVENT) boots and runs its timer.
- King of Fighters '96, Dragon Ball Z 4-in-1 and Dragon Ball: Dragon Mystery get past the blank
  screen, and Dragon Ball Z's graphics and saves work.
- Old NES dumps with "DiskDude!" headers load correctly.
- Vs. System games with old iNES headers get the right palette.
- NES colour emphasis darkens the picture as the hardware does instead of brightening it.
- NES sprites no longer appear on the top line, and the left-edge background mask works.
- Many NES games that drifted out of step with the real console now stay frame-for-frame with
  it, including PAL and Dendy games, Burai Fighter, The Punisher, Snake's Revenge and Top Gun 2.
- A crashed NES game keeps the screen running instead of freezing the whole emulator.
- Donkey Kong Country 3 keeps its sprites; Super Mario RPG's opening and attract demo play
  through; Yoshi's Island's intro keeps pace.
- Game Boy Advance games start with the screen in the right state.
- Loading a game is the one and only power-on: no frontend resets what it just loaded.

## For developers
- Headless capture can write a screenshot every K frames.
- Hundreds of new SNES test ROMs and audio goldens run in CI, from blargg, PeterLemon, gilyon,
  undisbeliever, absindx and krom, plus NESER's own suites.
- The gate now type-checks the web frontend, runs doctests, and covers every buildable feature
  set; CI shards the Rust and web integration tests.
- The Rust toolchain is pinned, and much shared code was consolidated: one console table for the
  web, one Game Boy core for DMG and CGB, one ROM-extension table.
