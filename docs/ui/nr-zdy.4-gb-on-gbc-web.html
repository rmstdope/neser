Game Boy games on a Game Boy Color, on the web — agreed

A choice in the side panel, under the game pickers, says which console original Game Boy games run on: “Game Boy” (the first time) or “Game Boy Color”. It is remembered in this browser. It takes effect when an original Game Boy game starts or is Reset; changing it mid-game never interrupts the game. Game Boy Color, NES, Super Nintendo and Game Boy Advance games are not affected. The new control is outlined in yellow only to point it out.
