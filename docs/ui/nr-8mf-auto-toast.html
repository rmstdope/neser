Option A — name it when there is a name, “game’s own” otherwise

Recommended: the player still learns the name when one exists, and is told plainly when the tint is the game’s own.

Only when an original Game Boy game runs as if on a Game Boy Color and F8 wraps back to Auto. Most well-known games (Zelda, Pokémon Red, Tetris, Dr. Mario, Donkey Kong…) get a tint made just for them by the Game Boy Color, which is not one of the twelve named palettes — so there is no name like “Dark Green” to show. Games the console doesn't recognise still get Dark Green.
