Playing an SNES Mouse game with the mouse — agreed

Desktop and web. Every recognised SNES Mouse game (SD Gundam GX, Mario Paint and the rest) gets the SNES Mouse connected automatically, in the port the game expects, unless the player chose a controller for that port in their settings. The other port stays a controller. Works like the Super Scope (docs/ui/nr-yvv-super-scope.html), except as noted.

SNES Mouse connected — click the game to use the mouse

1. Just loaded. The normal pointer shows over the picture. The message fades after a few seconds.

2. First click: the mouse is captured and the desktop pointer disappears. The click goes no further, so no dot is painted. The game draws its own pointer; the emulator draws no sight.

3. Playing. Clicks reach the game. Moving the mouse across the picture moves the game's pointer across the game screen at any window size; the game's own speed setting applies on top.

Mouse released — click the game to use it again

4. After Escape, or when the window loses focus: the normal pointer returns. The next click only captures again.

SNES Mouse connected — click the game to use the mouse

5. Narrow web window: the message wraps inside the picture.

SNES MouseWhat the player does

The keyboard controller does nothing for the port the mouse is in.
