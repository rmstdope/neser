F8 switches Game Boy Advance colours — agreed

In a Game Boy Advance game, F8 (desktop and web) and the web Colors button switch between raw colours and the GBA screen look, with the same corner message as the Game Boy Color. Chosen: “Colors: GBA screen”; each console remembers its own choice; plain-words settings text.

each console remembers its own

Game Boy Color and Game Boy Advance keep separate choices, just as they have separate settings today. Switching one never changes the other.

One session: the player switches the colours in a Game Boy Color game, then opens a Game Boy Advance game (Ctrl+O on desktop, or loading another game on the web page), then goes back to a Game Boy Color game.

Settings file (example), Game Boy Advance colour block

# GBA LCD color correction.
# When enabled, colors are darkened and softened the way the Game Boy Advance
# screen showed them: most of the picture's detail sits in the brighter half
# of each color. Screenshots and captures use it too.
# At runtime, press F8 in a Game Boy Advance game to switch it; this setting
# only decides how each start begins.
# Default: false (raw colors).
#gba-color-correction=false
