SNES DSP-2 firmware — agreed

Dungeon Master (DSP-2) follows everything agreed for DSP-1 (docs/ui/nr-auv-dsp1-firmware.html), plus: a per-chip sidebar in the browser version, and a check that the file really is the right chip's firmware — applied to every chip.

Option A — one row per chip, each with its own Replace… and Forget

Browser version. Once a DSP-2 file is stored alongside DSP-1, the “SNES firmware” block lists each stored chip on its own row. Each row has its own buttons, so forgetting a bad DSP-2 file leaves the DSP-1 file alone. Chips with nothing stored are not listed. When the last row is forgotten, the block disappears (as agreed for DSP-1). — it is how browser emulators list BIOS files, and it scales to DSP-3, DSP-4 and the rest.

Cost: the block grows by one line per chip; with all six chips stored it is six rows tall in a sidebar that already scrolls.

Option B — recognise the real firmware and refuse anything else

Neser knows the fingerprint of the genuine DSP-2 firmware. A file of the right size that is not it is refused with its own message, on the desktop strip, on the command line and in the browser dialog. The same check would then be added to DSP-1, changing what was agreed there (it only checked size).

Option A — DSP-1 gets the same check, so every chip behaves alike

Every word a player reads for DSP-2, exactly as it would ship. With this option, the DSP-1 messages also get a “right size, wrong file” line (the same wording with DSP-1 and dsp1b.rom), and the settings file says so for every chip. — a player sees the same behaviour whichever chip their game uses.

Settings file (the SNES firmware block, updated)

# Folder holding SNES coprocessor firmware files.
# Some SNES cartridges carry a math chip (DSP-1, DSP-2) whose program is
# stored in the chip itself. Game dumps do not contain it, and NESER cannot
# include it, so these games need a firmware file you supply, placed in this
# folder under its usual name:
#   dsp1b.rom  - DSP-1B (Super Mario Kart, Pilotwings, and most DSP-1 games)
#   dsp1.rom   - original DSP-1 (used instead of dsp1b.rom when present and
#                the game was built for the original chip)
#   dsp2.rom   - DSP-2 (Dungeon Master)
# Each file must be the genuine firmware for its chip, exactly 8192 bytes.
# Default: ~/.neser/firmware
#snes-firmware-dir=/absolute/path/to/firmware
