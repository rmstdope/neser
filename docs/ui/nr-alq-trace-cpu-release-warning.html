CPU trace in a release build — help line and warning

Shown once, at start-up, on the error stream, and only in a release build. It names whichever spelling you typed (--trace or --trace-cpu). In a debug build, or without the flag, nothing new appears.

neser --help (same text in every build)

$ neser --help
...
Trace and Debugging:
  --trace             Enable CPU trace output (instructions only in debug builds)
  --trace-cpu         Enable CPU trace output (instructions only in debug builds)
  --debugger-alpha    Debugger window opacity: 0.1 (transparent) to 1.0 (opaque, default: 0.7)
  ...

Release build, headless run

$ target/release/neser --headless --trace-cpu --output out.png game.nes
warning: --trace-cpu: this release build prints CPU interrupts only; build without --release for instruction lines
[CPU] NMI ...
[CPU] NMI ...

Release build, windowed, typed as --trace

$ target/release/neser --trace game.nes
warning: --trace: this release build prints CPU interrupts only; build without --release for instruction lines
[CPU] NMI ...

Debug build — no warning

$ target/debug/neser --headless --trace-cpu --output out.png game.nes
C000  78        SEI ...
[CPU] NMI ...
