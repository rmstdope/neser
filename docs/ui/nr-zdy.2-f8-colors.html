F8 switches Game Boy Color colours — agreed

In a Game Boy Color game, F8 (desktop and web) and the web Colors button switch between raw colours and the GBC screen look, with the same corner message. Chosen: message matches the button; the button shows the message too; short help line; the choice carries on until quit; both guides mention F8.

message matches the button

The message repeats the button’s own words, so the player sees one name for this everywhere.

A Game Boy Color game is running. Each press of F8 (desktop or web) switches the colours at once and shows this message in the corner, exactly like the palette messages on the NES and Game Boy. On the web the Colors button in the top bar changes with it.

both guides mention F8

The written guides players read: the example settings file and the Game Boy guide. New or changed text is highlighted.

Example settings file

# Game Boy Color LCD color correction.
# When enabled, colors are mixed and brightened the way the Game Boy Color
# screen showed them: softer and paler than the raw colors. Applies to
# everything shown in color, including black-and-white games the Game Boy
# Color colorizes. Screenshots and captures use it too.
# At runtime, press F8 in a Game Boy Color game to switch it; this setting
# only decides how each start begins.
# Default: false (raw colors).
#cgb-color-correction=false

Game Boy guide, colour-correction paragraph

It applies to everything shown in color, including black-and-white games the Game Boy Color colorizes. F8 switches it while a Game Boy Color game is running (desktop and web). In the web frontend, the “Colors” button in the top bar switches it while a color game is running.
