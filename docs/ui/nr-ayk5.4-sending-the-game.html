Play together — two browsers connect with two codes

The agreed design. Response time limits: Great under 50 ms, Playable 50–120 ms (warning), Too slow above 120 ms (refused when connecting; shown red but kept if it happens later). Sending the game and starting it come in a later piece of work.

Where it starts

Option A — one “Play together” button in the top bar

Always in the same place, in the library and while playing. It opens one window that asks Host or Join. Hosting needs a NES or Super Nintendo game running; otherwise that choice is greyed with the reason.

Play together — sending the game and starting together

The agreed design. Follows on from connecting (docs/ui/nr-ayk5.3-play-together.html): the host presses Start game, the game is sent with progress on both sides, and both start from the host's current moment after a count. The received game is not kept.
