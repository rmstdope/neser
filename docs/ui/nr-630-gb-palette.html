Game Boy shade palettes — agreed

Chosen drawings for choosing and cycling the original Game Boy palette.

Option A — four palettes

The Game Boy shade palettes a player can choose between, in the order F8 steps through them. Each screen is the same game frame drawn in that palette.

Grey

What you see today — stays the starting palette.

DMG Green

The original 1989 Game Boy's pea-green screen.

Pocket

Game Boy Pocket: olive-grey, near-black darkest shade.

Light

Game Boy Light (Japan only) with its backlight on: blue-green.

F8 in an original Game Boy game: Grey → DMG Green → Pocket → Light → back to Grey

Option A — the LCD look follows the chosen palette

With the Game Boy LCD look (the dot-matrix screen effect) switched on, the player picks Pocket with F8. The screen keeps its dot-matrix grid and motion blur, but in the Pocket colours.

Palette: Pocket

LCD look on + Pocket → a Pocket-coloured dot-matrix screen. Every palette works with and without the LCD look.

Option A — LCD look starts green

A player who already uses the Game Boy LCD look and has never chosen a palette. Today their screen is green. With this option it stays green: when the LCD look is on and no palette was chosen, the starting palette is DMG Green. Without the LCD look the starting palette is Grey, as today.

LCD look on, nothing chosen

LCD look off, nothing chosen

F8 with the LCD look on starts from DMG Green: DMG Green → Pocket → Light → Grey → DMG Green

The words, exactly

Every word a player reads for this change, written the same way as the NES palette's words. The default line assumes Option A for the LCD look.

Settings file, new block after the NES palette
# Preset Game Boy shade palette for original Game Boy (DMG) games.
# Game Boy Color games are not affected.
# Allowed values (case-insensitive):
#   grey      - Neutral grey shades (preserves prior behavior).
#   dmg-green - The original Game Boy's green screen.
#   pocket    - Game Boy Pocket's olive-grey screen.
#   light     - Game Boy Light's backlit blue-green screen.
# "gray" is accepted as another spelling of grey.
# An unknown value is ignored with a warning and the default palette is kept.
# At runtime, press F8 in an original Game Boy game to cycle through these palettes.
# The Game Boy LCD filter (gb-filter=dmg) is drawn in this palette.
# Headless capture (--headless) uses this palette too.
# Default: grey (dmg-green when gb-filter=dmg)
#gb-palette=grey
