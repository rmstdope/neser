GBA screen filters on the web (agreed)

GBA games on the web get the desktop looks through F4 and the Filter button; desktop drops the look-alike “GBA LCD”.

The looks

The same five looks on web and desktop. Desktop no longer offers “GBA LCD”, which looked exactly like None.

NoneRaw pixels, as today
AGB-001The original GBA screen: dark, muted, visible pixel grid
Switch OnlineColours as Nintendo Switch Online shows GBA games
GBA SPColours of the backlit GBA SP (AGS-101) screen
LCD GridPixel grid with a GBA console drawn around the picture

Web: the Filter button and F4

None → AGB-001 → Switch Online → GBA SP → LCD Grid → None. The button always names the look; no corner message on the web. Works while paused. The Colors button is independent and combines with any look.

Web: a look being fetched the first time

The button moves on at once; the old picture stays until the new look is ready.

Could not fetch (offline)

The picture stays on the previous look and the button goes back to its name. The next press moves on as usual.

Web: switching consoles

A GBA game loaded after an NES, SNES or Game Boy game starts on None (GBA games have none of their looks). A game of another console loaded after a GBA game on a GBA look starts on that console’s own starting look. A reload forgets the choice.

Desktop: F4

None → AGB001 → NSO-GBA-COLOR → SP101-COLOR → GBA-LCD-GRID → None. Messages unchanged, without GBA-LCD.

Desktop setting

neser.conf
# Shader/filter preset (Game Boy Advance).
# Valid values:
#   - none          : No filter, raw pixels
#   - agb001        : AGB-001 handheld preset
#   - nso-gba-color : Nintendo Switch Online GBA color preset
#   - sp101-color   : GBA SP-101 color preset
#   - gba-lcd-grid  : GBA LCD grid + border preset
# Leave empty or comment out for no shader.
#gba-filter=agb001

gba-filter=gba-lcd (or --gba-filter gba-lcd) is now refused exactly as any other wrong value is.

The pictures are stand-ins drawn by hand, not the real filters.
