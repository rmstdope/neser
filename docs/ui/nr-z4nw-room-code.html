Play together — one short room code

The agreed design. The host is shown a six-character room code to read out (or copy); the joiner types it and the two connect. A code lasts 15 minutes and is renewed by itself. Every state is shown with its words exactly as they ship. The Play together button, the first window (Host this game / Join a game), the Connected view, the response-time words and the top-bar chip stay exactly as they are today.
