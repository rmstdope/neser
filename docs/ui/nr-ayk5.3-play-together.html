Play together — two browsers connect with two codes

The agreed design. Response time limits: Great under 50 ms, Playable 50–120 ms (warning), Too slow above 120 ms (refused when connecting; shown red but kept if it happens later). Sending the game and starting it come in a later piece of work.

Where it starts

Option A — one “Play together” button in the top bar

Always in the same place, in the library and while playing. It opens one window that asks Host or Join. Hosting needs a NES or Super Nintendo game running; otherwise that choice is greyed with the reason.

Response time when connecting

Option A — a word and the number; too slow is refused

Response time (there and back) shown as a number plus one word. Great under 50 ms, Playable 50–120 ms with a warning, Too slow above 120 ms and play is refused. Recommended: a player can't feel a number, the word tells them; and refusing protects them from a game that feels broken. Exact limits are adjustable.

Closing the window while connected

Option A — closing the window keeps the connection

Once connected, ✕ or Esc closes the window but the two stay connected. The top-bar button turns into a status chip showing the response time; pressing it reopens the window, where Disconnect lives. Recommended: it keeps the screen clear while showing that you're connected (like a call-in-progress indicator). Before connecting, closing the window simply cancels.

When the connection gets slow later

Option A — stays connected; the word and colour follow the connection

The response time is checked once when connecting: too slow there and the connection is refused, as agreed. After that it keeps updating. If it gets too slow, the chip turns red and the window says “Too slow”, but nothing is cut off; it goes back to green when the connection recovers. Recommended: a short hiccup doesn't throw two players apart.

While the Play together window is open, the host's game is paused, like when Settings is open. Recommended: the host is busy copying and pasting, not playing, and the game will restart from a shared starting point anyway once both are connected.

Keyboard

Option A — no keyboard shortcut

Reached with the mouse or by tabbing to the top-bar button; Esc closes the window. When it opens, keyboard focus lands on the first button (Host this game, or Join a game when hosting isn't possible); Tab moves through the steps' buttons; on a paste step focus lands in the paste box. Recommended: it's used rarely, and keys are better kept for things players press often.
