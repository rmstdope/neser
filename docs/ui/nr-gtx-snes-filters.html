SNES screen filters (agreed)

SNES games get the NES looks, chosen with F4, the web Filter button and a setting of their own, exactly like the other consoles.

The same looks NES games have, in the same order. The pictures are stand-ins, not the real filters.

Desktop setting

neser.conf
# Shader/filter preset (SNES).
# Valid values:
#   - crt    : CRT simulation with scanlines, shadow mask, bloom
#   - ntsc   : NTSC composite video simulation
#   - smooth : Smooth pixel upscaling (xBRZ)
#   - pal    : PAL composite video simulation
#   - none   : No filter, raw pixels
# Leave empty or comment out for no shader.
#snes-filter=crt

Also --snes-filter crt on the command line. Left out, SNES games start on None. A wrong value is refused the way the other consoles’ filter settings refuse one.

Wide scenes

When a game switches to its high-resolution mode mid-game, the chosen look stays on.
