Option A — add Mesen2's colours as a new choice

Nothing changes for a player who does nothing. Mesen2's colours are one more F8 choice and one more nes-palette value.

First start, nothing configured

PUSH START

NESER's own white #ECEEEC   Mesen2's white #FFFEFF

Picture looks exactly as today (NESER's own white).

After pressing F8 until it appears

PUSH START
Palette: Mesen

Chosen colours are kept for the rest of the session; set nes-palette=mesen to start with them.

F8 cycle

Default → NesDev → Smooth → Classic → Composite Direct → Mesen ↺

Bold = what you get with no setting.

Option A — a capture uses the same colour setting as the window

--nes-palette (or nes-palette= in the config file) now works with --headless too. No setting: NESER's starting colours, same as the window.

$ neser --headless --frames 120 --nes-palette mesen --output neser.png power_up_palette.nes $ python -m scripts.diff_screenshots neser.png mesen.png --shift-search 1 0 px differ $ neser --headless --frames 120 --output neser.png power_up_palette.nes # no palette given → NESER's starting colours, exactly like the window; a Mesen2 diff shows the white difference $ neser --headless --nes-palette bogus --output x.png rom.nes Invalid --nes-palette value: 'bogus'.
