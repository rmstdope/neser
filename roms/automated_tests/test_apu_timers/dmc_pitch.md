# DMC Pitch Audio Expectations

This document describes the expected sound output for the `dmc_pitch.asm` test.

High‑level summary (matches the comment):

1. Sixteen tones, one per DMC rate index, with a steady (unchanging) timbre.
2. Each tone is compared against a CPU‑timed $4011 “square‑ish” DAC toggle at the same pitch.
3. Minor pitch drift can occur even on hardware (per test note).

Below is the detailed, explicit breakdown in order.

## Timeline (approximate)

### **Initial setup / hardware delay**

- The routine waits briefly for hardware to settle.
- NMI is disabled.
- The DMC sample is stored at $E000 and prepared for playback.

```none
$4012 = $80  ; sample address = $E000
$4013 = $01  ; sample length = 17 bytes
$4010 = $4F  ; loop=1, rate index=15
$4015 = $10  ; enable DMC
```

**What you hear:**
A looped DMC sample begins (triangle‑like timbre), but it is immediately used as a pitch reference for the test sweep. The exact audible onset is not emphasized; the main point is the pitch changes that follow.

### **Main frequency sweep (16 tones total)**

The test loops `entry` from 15 down to 0. For each entry:

```none
$4010 = $40 | entry  ; loop=1, rate=index
```

Then it plays two simultaneous pitch references for a short duration:

1) **DMC playback** at the selected rate (unchanging timbre).
2) **CPU‑timed $4011 DAC toggling** that produces a “square‑ish” pitch at a matching frequency.

The CPU‑timed pitch is generated by tight delay loops and repeated $4011 writes (two consecutive writes per toggle) with a small duty‑like offset. This makes the CPU‑generated tone act as a pitch comparator for the DMC tone.

**What you hear (for each step):**

- A steady‑timbre tone from the DMC at the selected rate index.
- A second, more synthetic “buzzy” reference tone from $4011 at (approximately) the same pitch.
- Each pair lasts a short, consistent interval before moving to the next rate.

**Total sequence:**

- 16 pitches in descending index order (rate 15 → 0).
- The timbre of the DMC tone should not change between steps, only the pitch.

### **End**

```none
$4015 = $00  ; disable DMC
```

**What you hear:**
Silence forever.

## Total audible sequence (human‑ear version)

1. (Brief setup) DMC sample begins.
2. Sixteen tones, stepping through all DMC rate indices from 15 down to 0.
   - Each step has a DMC tone plus a CPU‑timed $4011 reference tone.
   - Timbre stays steady; pitch changes each step.
3. Silence forever.

## Notes / common failure indicators

- If a tone **continually shifts** in pitch within a step, the corresponding DMC rate table entry is likely wrong.
- If **all** tones drift, check timer period handling, DMC DMA wait‑state addition, and CPU instruction timing.
- The test author notes slight pitch drift can happen even on hardware; compare against `dmc_pitch.wav` for expected behavior.
