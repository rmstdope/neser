# GBEmulatorShootout acid test ROMs

This directory contains acid test ROMs vendored from GBEmulatorShootout:

<https://github.com/gbdev/GBEmulatorShootout/tree/main/testroms/acid>

Vendored upstream commit: `0464f9077abd7355943d47654d4970af33c8527b`.

GBEmulatorShootout is distributed under the MIT license. The vendored files are:

- `which.gb`
- `dmg-acid2.gb`
- `cgb-acid2.gbc`
- `cgb-acid-hell.gbc`

`which.gb` is used by the Shootout for both DMG and CGB rows.
