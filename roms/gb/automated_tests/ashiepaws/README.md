# Ashiepaws GBEmulatorShootout ROMs

This directory contains Ashiepaws test ROMs and reference screenshots vendored
from GBEmulatorShootout:

<https://github.com/gbdev/GBEmulatorShootout/tree/main/testroms/ashiepaws>

Vendored upstream commit: `0464f9077abd7355943d47654d4970af33c8527b`.

GBEmulatorShootout is distributed under the MIT license. The vendored files are:

- `bully.gb`
- `bully.png`
- `strikethrough.gb`
- `strikethrough.png`

Original upstream projects:

- BullyGB: <https://github.com/Ashiepaws/BullyGB>
- strikethrough.gb: <https://github.com/Ashiepaws/strikethrough.gb>

Both original upstream projects are distributed under the MIT license.

GBEmulatorShootout runs `bully.gb` as both a DMG and CGB row, and
`strikethrough.gb` as a DMG row.
